# Weeb – Site Vitrine

Projet frontend pour l’entreprise **Weeb**.
Développé avec **React**, **TypeScript**, **Vite** et **Tailwind CSS**.

---

## 🛠 Stack technique

- **Framework** : React + TypeScript
- **Build Tool** : Vite
- **CSS** : Tailwind CSS
- **Routing** : react-router-dom
- **Versioning** : Git + GitHub (Gitflow avec develop / feat branches)

---

## 📌 Fonctionnalités

- Pages **Home**, **Contact**, **Login**
- Navigation avec **React Router**
- Design basé sur la **maquette Figma** du client
- **Responsive** : Mobile, Tablette, Desktop
- Composants réutilisables pour faciliter l’évolution future
